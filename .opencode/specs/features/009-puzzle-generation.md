# Feature 009 — Puzzle Generation

## Goal

Convert verified tactical opportunities into training puzzles.

## Requirements

- multi-move solutions
- tactical objectives
- solution verification
- alternative solution handling
- provenance
- difficulty metadata
- generation version

Tactical-motif detection and labeling are not required. The puzzle
must record its tactical objective but not a motif label.

## Acceptance Criteria

Every puzzle can be traced to the user's game.

Every solution is legal.

Puzzle verification data is stored.
